# 智慧教育一体化平台 · Demo

一个面向「智慧教育」场景的一体化管理平台演示网站，覆盖教学、校园管理、学情分析、在线考试、资源共享与数据可视化等核心模块。纯前端单文件实现，无外部依赖，开箱即用。

在线预览：<https://hebugui.github.io/smart-education/>

## ✨ 功能模块

| 模块 | 说明 |
| --- | --- |
| 🏠 工作台 | 六大核心模块概览、今日日程、平台实时动态 |
| 📚 智慧教学 | 课程列表、AI 作业批改、互动课堂（随机点名/抢答/推送测验/弹幕） |
| 🏫 校园管理 | 学籍统计、教务审批流转、智能排课、公告发布 |
| 📊 学情分析 | 成绩趋势折线图、能力雷达图、知识点掌握饼图、AI 诊断报告 |
| 📝 在线考试 | 进行中考试、智能组卷、在线答题、防作弊监考 |
| ☁️ 资源共享 | 资源卡片检索、热门排行、教育均衡数据 |
| 🖥️ 数据大屏 | 深色风格决策大屏，区县指数柱状图、师资环形图、实时预警与 AI 建议 |

## 🚀 快速开始

项目为纯静态网页，无需安装依赖。

**本地运行**：直接用浏览器打开 `smart-education-demo/index.html`，或启动静态服务器：

```bash
python -m http.server 8000
# 浏览器访问 http://localhost:8000/smart-education-demo/
```

**在线访问**：GitHub Pages 已部署，见上方链接。

## 📱 响应式适配

支持桌面端与移动端：

- 桌面端：侧边栏导航 + 多列网格布局
- 移动端（≤768px）：汉堡菜单抽屉导航、网格单列化、表格横向滚动
